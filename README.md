📊 Netflix Analysis Dashboard – Power BI

📌 Overview
This repository contains a **Power BI dashboard** that analyzes Netflix’s global content library. The dashboard provides interactive insights into the distribution of movies and TV shows, ratings, release trends, and country‑wise availability.



🎯 Key Insights
- **Total Titles**: 8,805  
  - Movies: 6,128 (≈69.6%)  
  - TV Shows: 2,676 (≈30.4%)  
- **Ratings Distribution**:  
  - TV‑MA (3.2K), TV‑14 (2.2K), TV‑PG (0.9K), PG‑13 (0.5K), others in smaller proportions  
- **Growth Over Time**: Clear increase in titles from 1950 to 2020+  
- **Regional Spread**: World map visualization showing country‑wise availability of Netflix content  



🛠️ Features
- **Pie Charts**: Breakdown of movies vs. TV shows  
- **Line Graphs**: Growth of Netflix’s catalog over decades  
- **Bar Graphs**: Ratings distribution across titles  
- **World Map**: Geographic distribution of Netflix content  
- **Interactive Filters**: Show Type, Release Year, Country  



📂 Data Source
- Netflix dataset including: Title, Type, Release Year, Genre, Country, Duration, Ratings  
- Data cleaned and transformed using **Power Query** in Power BI  



⚙️ Technical Details
- Built with **Power BI Desktop**  
- Uses **DAX measures** for calculations (e.g., counts, growth rates)  
- Interactive slicers and drill‑through functionality  
- Optimized visuals for clarity and performance
